# 📊 MarkToCanvas (`mark-to-canvas`)

A lightweight Python compiler that converts Markdown files into interactive, animated HTML5 Canvas presentations.

## ✨ Features

- **Zero External Dependencies:** Built purely with Python standard libraries (`argparse`, `json`, `re`, `pathlib`).
- **Interactive HTML5 Canvas:** Renders slides smoothly with dynamic particle animation backgrounds.
- **Keyboard Controls:** Use `ArrowRight`, `ArrowLeft`, or `Spacebar` to navigate through slides.
- **Responsive Layout:** Auto-adjusts canvas scaling based on screen size and aspect ratio.
- **Code Block Support:** Displays pre-formatted code snippets within custom UI containers.
